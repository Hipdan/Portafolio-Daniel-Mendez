#### Portafolio personal - Daniel Mendez - 17-EISN-2-021

Portafolio web personal responsive y minimalista. Diseñado para presentar proyectos, informacion sobre mi, y redes sociales.

---

## Tecnologías Utilizadas

* **HTML5:** Estructura sencilla, sin frameworks ni cosas innecesarias.
* **CSS3:** Estilos personalizados, CSS Grid y animaciones.
* **Google Fonts:** Tipografías Inter y Poppins.

---

## Características y Funcionalidades

* **Diseño Responsive:** Adaptabilidad completa a dispositivos móviles, tablets y monitores de escritorio mediante Media Queries .
* **Arquitectura de Tarjetas de Proyectos:**
  * Distribución en Grid.
  * Alineación vertical de contenido.
  * Tarjetas cliqueables con enlace directo a los proyectos activos y redes sociales.
* **Optimización visual:** Tema oscuro profundo para evitar la fatiga visual, Dedagrado de colores para darle un estilo moderno, efectos hover y ajuste de imagen de perfil mediante.
